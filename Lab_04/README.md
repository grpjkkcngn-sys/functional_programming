# Лабораторна робота №4 (Варіант 8: Дерево математичного виразу)

## Опис
Модель дерева арифметичних виразів (`Num`, `Add`, `Sub`, `Mul`), чисте рекурсивне обчислення `eval_expr`, мемоізована версія `eval_expr_memo` з `@lru_cache`, підрахунок вузлів, висота дерева та ітеративний обчислювач `eval_expr_iterative`.

## Ліміт рекурсії та відсутність TCO
У CPython максимальна глибина стеку викликів за замовчуванням становить близько 1000 кадрів (`sys.getrecursionlimit()`), і при її перевищенні виникає `RecursionError`. Оптимізація хвостової рекурсії (TCO) у CPython не реалізована, тому для глибоких дерев безпечніше застосовувати ітеративний алгоритм із власним стеком (`eval_expr_iterative`).
