# Лабораторна робота №1 (Варіант 8: Аналіз банківських транзакцій)

## Опис
Програма реалізує аналіз банківських транзакцій у функціональному стилі. Чисте ядро відбирає успішні операції, конвертує суми у базову валюту (UAH), фільтрує транзакції за мінімальним порогом та обчислює комісію без мутації вхідних даних і без глобального стану. Політики конвертації, нарахування комісії та фільтрації передаються через `typing.Callable`.

## Структура проєкту
- `core.py` — типізовані структури (`TypedDict`), чисті функції предметної області та фабрика `make_transaction_processor`.
- `app.py` — налаштування політик, тестові дані та ізольований консольний вивід звіту (I/O).
- `tests/test_core.py` — модульні тести (`pytest`) на референтну прозорість, відсутність мутацій та коректність `Callable`-політик.
- `pyproject.toml` — налаштування `pytest`, `mypy`, `black` та `ruff`.
- `requirements.txt` — список залежностей.

## Запуск
```bash
python3 app.py
pytest -q
mypy core.py app.py tests/test_core.py
```
